## 当前继续推进

个人计划库、[逐动作时间记录](history/MOVEMENT_TIMING_V0_11.md)及[纵向历史](history/LONGITUDINAL_HISTORY_V0_12.md)已完成软件验收；[动作内容与真实验收入口](validation/ACCEPTANCE_READINESS_2026-09-10.md)也已完成盘点并提供登记模板和检查工具。本轮续建范围完成，真人、素材与硬件的最终验收仍需对应条件。

后续接入摄像头时，可按[双摄说明](history/DUAL_CAMERA_V0_13.md)先测试两路原始画面。开发工具 `check_dual_camera.py` 可记录显式选择的设备同时采集、实际帧参数及停止重开；不会推理或保存视频，不能代替真人动作对照。

优先完成一项真人肩外展的完整路径：独立相机测试 → 选择动作与测试侧 → 正式预览和确认 → 对照动作识别与计数 → 保存 → 关闭重开报告。接着验证坐站，再按所需场景选取扩展动作。每次只对已取得的证据作结论。

如先使用录像，需要记录来源和人工对照，保留 `REPLAY_FILE` 标签；软件合成测试继续标记 `SYNTHETIC/TEST`。目标完成与否应以可复核结果判断，不能用按钮数量、示范图或测试总数代替。
