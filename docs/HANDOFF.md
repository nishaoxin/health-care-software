## 当前继续推进

个人计划库和[逐动作时间记录](history/MOVEMENT_TIMING_V0_11.md)已完成软件验收，继续实现条件可比的历史。代码阶段的完成不替代下面的真人验收路径。

优先完成一项真人肩外展的完整路径：独立相机测试 → 选择动作与测试侧 → 正式预览和确认 → 对照动作识别与计数 → 保存 → 关闭重开报告。接着验证坐站，再按所需场景选取扩展动作。每次只对已取得的证据作结论。

如先使用录像，需要记录来源和人工对照，保留 `REPLAY_FILE` 标签；软件合成测试继续标记 `SYNTHETIC/TEST`。目标完成与否应以可复核结果判断，不能用按钮数量、示范图或测试总数代替。
