## 本轮范围

用户反馈双摄目前可用，本轮聚焦“下一步做什么”、头前屈取景解释，以及用户能读懂的康复测试报告。没有打开用户摄像头，没有修改用户数据库、虚拟环境、模型权重、双摄配对、测角、计数或测量版本。未生成或下载动作图。

## 实际操作变化

- 动作页默认“步骤”，每步显示编号、大字操作和下方主按钮。普通动作、反向起点动作、方向校准、坐站分别按现有定义生成步骤。
- 拍摄位置确认只是界面进度，不代替后台就绪检查。起点 / 方向仅在原记录命令成功后推进；失败留在当前步骤提示具体原因。通过“设置”仍可更换侧别、机位和重录。
- “人工核对”给出明确复选框：本人、测试侧、关节点、回到起点；双摄还包括两路同一人和正侧角色。陪同要求另行确认。主按钮不会替用户勾选。
- 训练先选择可用评估，再确认个人计划；未就绪时提供补齐入口，开始按钮仍被门禁禁用。已有组间确认、暂停、实时大字指导、两路释放和保存失败处理不变。
- 评估完成并成功保存后读取已保存的记录 ID，自动打开报告并汇总身体档案。训练保存后先填写或跳过感受，再显示报告。重复保存通知不重复自动打开；保存失败不展示成功报告。

## 头前屈 / 后伸为什么要求髋

当前代码 `head_pitch` 使用同侧肩—髋方向作为躯干参考、耳—眼方向作为头部参考，报告相对本次舒适起点的二维变化。髋不是被测关节，而是躯干参考的端点；侧面相机仍需看到它，不能把正面髋坐标拼到侧面。

界面明确说明：穿衣即可，但人体轮廓必须可辨；取景到同侧髋部，不必拍到脚、远侧肩或露出皮肤。未新增无需髋的头部俯仰模式，也没有把缺髋时的屏幕垂直角伪装成原头颈测量。头部和躯干都发生运动是颈部测量需要处理的问题，可参考[光学测量颈部活动的原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC6862302/)；该研究不验证本软件的关键点或二维代理方法。

## 报告的解释边界

报告首屏为“结果解读”，保留“详细数据”。HTML 导出同样包含解读；JSON、CSV 与数据库原始记录结构不改。

专业指标与通俗解释并列：任务完成、部分 / 中断尝试、原指标名与最小 / 最大投影角和可观察幅度、个人目标、有效观察时间和比例、出程 / 峰区或站位停留 / 回程 / 最长连续保持、可见规则表现。

- 范围复用原有效证据规则；旧记录派生时明确标记来源，不改写旧数据。无效范围显示缺测，不补零。
- 时间只从保存的各分项 `valid=true` 且有限非负的数值取中位数，并列明记录数；不从总时长补算，不把中断片段拼接。
- 有效观察比例不是准确率或合格率；次数不是功能等级；目标没设置不是失败；没有规则问题不等于完全正常。
- 头颈为整体二维投影观察，不是临床颈椎 ROM；双摄是主机位与独立辅助观察，不平均两路角度，不承诺三维或曝光同步。
- 只提供结果解释，不自动诊断、比较正常值、判断肌力、宣称改善或生成处方；文字仍需专业人员和实际使用者进一步审核。
