# 提示收敛与逐项有效性改进

2026-09-11，按用户给出的顺序实施。开发基线 `acd2dd0`，已保留 Git bundle 与本地数据备份。本轮不采集真人样本，不生成动作示范图。

## 已确认的要求

1. 数据有效性与界面打断独立：无效样本立刻排除，不补值、不计缺测时间、不显示旧角度；短暂波动先用小状态，持续缺测才给出一句可执行调整提示。
2. 普通与大字界面使用一致的提示优先级，同一问题只出现一次。普通信息自动消退，取景问题就地提示；身份歧义、设备失效和保存失败保留强门禁与恢复入口，停止按钮始终可用。
3. 双摄主指标与辅助指标分别标记有效性。两路当前人员归属明确、主路满足原测量要求时，辅助几何指标缺测不再否定主路。辅助路无人员证据、身份不明或任一路断流，不能借此继续使用不确定数据。
4. 准备阶段集中人工核对，起点 / 方向以就地步骤和可取消的倒计时采样减少弹窗；上下文、动作、侧别、参与者、机位变化后原确认仍失效。采样保持原有连续可见性与稳定性门槛。
