## 1. 本周真正部署的只有一个姿态前端

继续使用已冻结的`YOLO11n-pose`，通过统一PoseFrame提供人体框、COCO17点和质量信息。姿态、测角、动作分期、质量评价、事件任务是不同层次，不为每个关节或场景各装一个模型。已有MediaPipe模块可复用，但不并行再造另一条产品路线。

| 资源 | 现成能力与限制 | 本周用法 | 后续启动条件 |
|---|---|---|---|
| YOLO11n-pose | 官方有预训练姿态权重；不直接输出康复质量或跌倒结论 [R1,R2] | 唯一必需的姿态模型 | 本周不为“更新版本”换模型 |
| AIGym | 参考三点测角、阈值与计数实现 [R5] | 阅读即可；计数终点自己定义 | 不整段套默认阈值，不二次推理同一帧 |
| Sports2D | 单视频/摄像头的二维轨迹和角度分析，依赖姿态质量与拍摄平面 [R3] | 可选，独立环境查看同一段自有视频 | 不把结果当金标准，不移植OpenSim等额外链路 |
| Kinovea | 人工测角、计时和视频对照 [R4] | 可选，用同一帧、同一角度定义做参考 | 二维一致性不等于三维或疾病诊断验证 |
| STGCN-rehab | 作者提供康复评价训练/评估代码，要求匹配骨架与预处理；研究涉及KIMORE、UI-PRMD [R6] | 不安装、不接权重 | 规则版稳定且有独立人工标签后再研究质量层 |
| REHAB24-6 | RGB、二维/三维骨架、动作分段、二元正确性标签 [R7] | 不必下载；仅列研究候选 | 获得相应用途许可、匹配当前问题后选取 |

| Human-Falling-Detect-Tracks | 旧骨架时序跌倒参考；图定义为14节点并有特定预处理 [R8] | 只借鉴时序/上下文思路，不复制部署 | 明确许可、确认权重可用、输入契约匹配并完成独立测试 |

## 2. Sports2D怎样帮助排错，而不是拖慢开工

先完成主程序一个动作的保存/重开，确有必要再在**单独环境**运行作者的视频命令：[R3]

```text
sports2d --video_input demo.mp4
```

比较同一个参与者、同一时刻、同一个投影角度定义的曲线；重点看点是否跑偏、左右是否混用、角度内外定义是否相反。两个模型一致只是一条排错线索，不是标准答案。不要把参与者家庭视频上传到第三方在线演示站；优先本地、经授权的短片。

主程序运行时不再同时开Sports2D抢占摄像头。缺少这个工具不能导致主程序启动失败，也不应在本周为它更换Python或升级整个现有环境。

## 3. REHAB24-6的三处边界

作者记录中包含肩外展、Arm VW、桌上俯卧撑、腿外展、弓步和深蹲，**没有坐站**。提供的正确/错误是二元标签，不能直接把“错误”解释成屈肘或躯干侧倾；本项目的逐问题标签需要人工重新定义与复核。其26关节骨架也不是本项目COCO17输出。[R7]

作者明确限制学术或非营利机构的非商业研究，商业用途应联系授权。保留许可与引用，不把RGB/骨架或来源权重随产品重新分发，也不因“公开可下载”默认获得所有用途的权利。[R7]

后续在许可允许时，可用最终姿态前端重提取RGB视频，使模型输入格式与产品一致；这只能统一前处理，不能消除衣着、机位、人群和实验室/家庭之间的差异。标注帧与视频时间还需明确对齐。

## 4. 为什么不直接接旧跌倒权重

旧项目的`Actionsrecognition/Utils.py`规定14节点图；`ActionsEstLoader.py`还做坐标和动作差分处理。因此本项目的COCO17序列不能只改一个输入维度就直接使用。[R8]

应检查节点顺序、缺失点、坐标尺度、置信通道、时间采样、动作类别与权重来源。代码可浏览、权重链接存在、部署授权明确、实机检验通过，是四件不同的事；本次没有验证这些权重可下载或运行。仓库若没有清晰许可，应先澄清，不拷贝进发布包。

本周使用可解释的历史规则：异常下降或持续低位＋区域和动作上下文＋人工确认；保留时间与有效性，不将静态卧位或事后分类说成预测。

## 5. 稳定版本之后，按出错层决定投入

| 已定位的问题 | 应先做 | 不是现在就做 |
|---|---|---|
| 骨架合理，计数多/少一次 | 调整起止定义、回位门槛、迟滞和缺测处理，跑固定回归 | 不重新训练姿态模型 |
| 骨架合理，纠错频繁或不适合个人 | 调整个人目标与规则；保留阶段和人工标签 | 不把所有人套健康者标准 |
| 规则难以覆盖真实动作质量 | 先做特征基线，再比较小型多标签时序判断层 | 不先输出无法解释的0—100总分 |
| 髋膝腕持续定位错 | 先改机位和采集条件；积累人工修正的困难帧 | 不直接拿模型错误预测当真值训练 |
| 正常弯腰/坐下被当跌倒 | 增加真实正常活动负样本、场景及时序约束 | 不只扩增更多模拟跌倒正样本 |

训练只有在独立分组数据、许可、人工标签和冻结基线具备之后开展。先改善质量判断层，姿态定位确有问题才微调前端。新版本通过独立回归且可回退，才替换既有模型。

EGCN、RepNet、MotionBERT、MMAction2/PoseC3D、OmniFall等新提供的研究方向不进入本周安装清单；本次不展开训练流程，不给Codex批量下载数据或重写网络的任务。大量关节点、复杂网络或长资源清单都不是首周验收项。
