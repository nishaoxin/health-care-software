# 提示收敛与逐项有效性 · 0.14.0

2026-09-11。基线 `acd2dd0`（0.13.0）。范围来自本轮用户要求，按提示合并、波动缓冲、一句指导、双摄规则和准备流程实施。未采集真人或真实摄像头画面，未添加动作示范图、模型或依赖。

## 数据与提示各自负责什么

`SceneController` 与原有测量 / 计数引擎仍决定数据能否使用。新增 `GuidancePolicy` 只生成显示内容，由 Runtime 发送给普通和大字界面；不改变观察、角度阈值、完成次数或计时。

| 情况 | 数据处理 | 界面行为 |
| --- | --- | --- |
| 普通缺测持续不足 1.5 秒 | 当前帧立即排除；角度和当前时间读数清空，不补缺测时间 | 保留所选动作的一般文字指导，不沿用旧阶段图片；小状态“正在重新识别，当前不计次” |
| 持续缺测 | 原门槛继续生效 | 一次只提示一个需要入镜的部位；缺失目标改变需稳定 0.6 秒才替换，避免轮流跳字 |
| 恢复识别 | 从新的有效帧恢复原引擎处理，不回填 | 调整提示撤下，短暂显示“已重新识别”后消退 |
| 正常保存 / 起点记录 | 保留原持久化行为 | 约 4 秒自动消退，不要求点击 |
| 多人、可见但无法归属、人员跟踪变化 | 正式任务立即结束；保存门禁保留 | 单条明确提示，重新预览 / 确认入口 |
| 输入断流或模型推理异常 | 停止并释放任务输入；保存已有结果，保存失败保留待恢复对象 | 明确恢复提示，不允许只在显示上暂停、后台继续计数 |
| 保存失败 | 保持 `SAVE_FAILED`，阻止新任务覆盖结果 | 显示重试、备份和原有明确丢弃入口 |

普通界面在“怎么做”页显示指导；切到准备设置后，必要调整仍在画面旁可见。同一问题不同时重复放在顶部、画面下方和步骤区。大字界面的动作指导通常为一句已有动作内容，短状态使用较小字号。停止采集入口不受倒计时或普通忙碌状态遮挡；训练恢复的人工确认门禁不变。

缓冲时长是界面参数，不是医学阈值或降低测量门槛。提示设计参考 [Microsoft InfoBar 指南](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/infobar)关于避免快速闪现、重复状态和区分严重程度的建议。

## 双摄规则与报告

新有效性版本为 `primary-with-auxiliary-identity-1`。主路必要指标全部满足原条件、两路当前均为唯一可归属参与者并且接收配对有效时，辅助几何指标缺测不再整体阻断主测量。辅助路没有参与者证据时，主测量仍停用；多人、可见但没有跟踪归属、跟踪变化、输入或推理失败不适用这项放宽。

每项指标继续保存自己的 `valid / reason`。双摄逐帧记录新增 `identity_confirmed`、`main_measurement_usable`、`primary_used`，分别表示当前归属证据、主测量可用性和实际纳入；训练暂停帧不能因主指标可测而标记为已纳入。报告区分两路可测帧、主测量纳入帧与辅助整体缺测但主测量纳入帧，CSV 同步输出这些字段。原始主路指标仍作为观测证据保留，不等同于该帧已用于计数。

纵向比较版本更新为 `recorded-conditions-3`。0.13.0 的 `dual-2d-1` 历史记录未保存新字段时解释为 `all-views-required-1`，与新规则不能视为相同条件；不重写或重新计算旧报告。没有空间标定、曝光同步、跨机位补点或三维融合。

## 准备流程

起点 / 方向按钮直接说明需要先做的姿势。例如肩内收为“已侧抬臂，倒计时记录起点”，方向为“已按动作方向试做，倒计时记录”。点击后等待 3 秒，清除倒计时之前的历史，再尝试取得连续稳定的新观察；按原帧接收时间排除采样开始前的在途推理结果，不能把推理较晚完成视为新采样。采样窗口最长 4 秒，失败在原处提示重试。取消、停止、换动作 / 侧别 / 来源 / 参与者、跟踪或实际尺寸变化都会取消本次采样。

沿用至少 5 帧、跨度至少 0.8 秒、相邻帧间隔不超过 0.5 秒、最新样本不超过 0.3 秒的连续窗口要求。关节波动上限仍为 6°；坐站沿用膝角 10°、髋位置 0.03 的稳定上限，并修正为连续窗口，不过滤掉缺测后拼接。肩内收的起点分期空间和方向试探幅度门禁保留。

录像在倒计时后才请求新的 1.2 秒媒体预览片段，不能把等待的墙钟时间当成姿势稳定时长。坐站新基线还保存准备时的参与者 / 上下文绑定，换人后清除之前位置的值，确认时复核归属；数值比较仍只比较实际基线值。

单次最终人工核对放在固定操作区，切换页签也可见。确认不会自动开始；确认后、开始前的参与者或画面尺寸变化会使确认失效。新动作的起点、换人 / 移动机位后的核对、陪同需求和训练计划确认继续保留。
