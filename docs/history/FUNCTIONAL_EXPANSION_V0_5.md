## 当前覆盖

| 部位 | 已接入评估与训练的任务 | 尚未实现 / 不应混称的项目 |
| --- | --- | --- |
| 肩 | 外展、前屈、后伸、从外展起点内收回位 | 内外旋、水平内外收；需要专门机位和约束，不能拿抬举角替代 |
| 肘 / 前臂 | 屈肘、从屈肘起点伸肘 | 前臂旋前/旋后；手掌转动不能直接冒充桡尺关节旋转 |
| 腕 | 掌屈、背伸、桡偏、尺偏 | 多平面环绕、真实负重与关节稳定性 |
| 手指 | 拇指 MCP/IP；其余四指 MCP/PIP/DIP，各有屈曲起点与伸展起点两个往返任务 | 拇指 CMC、对掌、手指外展内收；尚需各自的测量契约和失效检查 |
| 髋 | 外展、内收、前屈、后伸 | 内外旋；需要分辨骨盆/机位变化与选定动作，不使用现有髋屈伸替代 |
| 膝 | 坐位伸膝、屈膝、居家坐站 | 超伸、肌力、负重或稳定性不能由当前屈曲投影角给出 |
| 踝 / 足 | 坐位背屈、跖屈 | 后足内外翻、足弓与足趾各关节；现有足跟和足尖点没有完整足趾链 |
| 头颈 | 头部相对身体参考线的前屈、后伸、侧屈观察 | 不是各颈椎节段活动度；轴向旋转尚未接入 |
| 躯干 | 整体前屈、后伸、侧屈观察 | 不分离胸腰椎各节段、骨盆和髋部贡献；轴向旋转尚未接入 |

合计 **53 项任务**，包括原 33 项、14 项手指反向起点任务和 6 项头颈/躯干整体观察。新增手指任务改变起点、出程和目标判断方向，不表示新增了 14 个解剖关节。每项保留左右侧记录，共 106 个入口；头颈/躯干侧屈的左右是活动侧，前屈/后伸的左右是拍摄测试侧，不是左右两个脊柱关节。

## 新增测量契约

所有头颈/躯干任务均标为实验性二维整体观察；先记录舒适起点，再用人工确认的小幅试动作标记活动方向。不能自动证明实际机位正确。坐稳、固定机位，按已确认的活动安排使用；不要求最大幅度，疼痛、头晕或不适立即停止。不能从本功能判定患者是否适合某种训练。

| 项目 | 原始投影定义 | 必要点和拒测条件 |
| --- | --- | --- |
| 头颈侧屈 | 双眼连线相对双肩连线的有符号夹角变化 | 双眼、双肩；肩线不足 40 像素或眼线不足 12 像素返回空 |
| 头颈前屈 / 后伸 | 同侧耳→眼向量相对髋→肩向量的夹角变化 | 指定侧眼、耳、肩、髋；躯干线不足 50 像素或耳眼线不足 12 像素返回空 |
| 躯干侧屈 | 髋中点→肩中点相对双髋连线的夹角变化 | 双肩、双髋；肩线不足 40、髋线不足 30 或躯干线不足 50 像素返回空 |
| 躯干前屈 / 后伸 | 同侧髋→肩向量相对图像竖直方向的变化，减去舒适起点 | 同侧肩、髋；躯干线不足 50 像素返回空；固定起点不能消除任务中相机移动或髋部贡献 |
| 手指伸展 | 沿用该关节原屈曲投影角，从已记录屈曲起点向减小方向活动，回屈到起点后计次 | 原有手指关节三点、短线段和时间连续性门禁；不测超伸，手部模型无逐点置信度 |

像素长度是保守工程拒测条件，不是医学阈值或精度保证。坐标均为同尺度原图像素，角度差按环形角处理；镜像、机位和来源变更仍需重新确认，不交换人体左右侧。原动作的公式不变。新增整体观察保存 `whole-segment-projection-1` 测量契约；不同契约或新旧契约未知时不直接比较。

现有 COCO17 骨架具有眼、耳、肩、髋等点，官方关键点清单见 [Ultralytics COCO-Pose 文档](https://docs.ultralytics.com/datasets/pose/coco/)。上述投影定义与拒测规则是本项目的工程设计，**不是该模型官方提供的康复能力或临床验证结论**。

## 本轮评估清单

- 当前用户、来源类型和使用情境下可建立一轮清单，手动选择项目/侧别，不按年龄或历史幅度自动开评估处方。
- 同一范围只保留一轮进行中的清单。结束后可创建下一轮，已结束清单与报告保留。
- 从清单选择项目后，仍走原来的预览→舒适校准→人工确认→开始→保存路径。开始前重新读取本地清单，拒绝已结束、已跳过、异用户、异来源或侧别不匹配项目。
- 本轮只统计带有该轮与项目引用的评估。训练、以前的记录和从普通单项入口开始的任务不会悄悄充当本轮结果。
- 最新尝试证据不足或异常中断显示需补测，不回退到旧成功；待测/需补测可填写原因跳过，跳过可恢复，不能用跳过盖住已评估结果。
- 结束本轮不等于所有项目完成，不删报告，不把未测变成 0° 或正常。清单不自动开启下一动作或摄像头。
- SQLite 升级至 v3 前先备份旧库，新增清单表；原会话和个人信息不改写。失败表单保留，后台冲突有明确提示；只读旧库不迁移。
