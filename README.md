# 居家康复助手

根据项目里的 v2.1 规范制作的 Windows 本地桌面应用。现在提供独立的身体评估、用户身体信息和训练指导入口，支持肩、肘、膝、髋的六项二维动作观察；四个业务场景依次使用一路输入。

**在当前电脑上，双击 `启动康复助手.cmd` 即可打开软件。** 独立环境和官方 YOLO11n-pose 权重已准备；程序启动不会自动打开摄像头，也不会自动下载模型。

使用顺序：确认当前用户编号 → 身体评估（选择动作、侧别和相机，预览并确认机位）→ 完成评估并汇总 → 在用户身体信息选择已有评估 → 进入训练指导 → 人工设置并确认训练计划 → 重新预览、确认机位并开始。也可先继续评估其他动作或左右侧。

当前动作：肩外展、肩前屈、肘屈伸、坐位膝屈伸、髋外展、居家坐站。只拍得到上半身时不要强行开展下肢动作。结果是摄像头平面投影与任务记录，不是临床关节活动度、肌力或诊断；训练目标不由评估最大角度自动生成。

当前为可运行的工程首版。自动测试和模型接入已验证；真人动作准确度、摄像头现场表现、USB 拔插和长期运行仍需独立验收。

本地数据、环境、权重和生成的测试文件不进入 Git；模型 hash 与完整依赖版本已记录。当前功能范围增补见 [评估与训练扩展](rehab_codex_single_camera_v2_1/docs/ASSESSMENT_TRAINING_V0_2.md)。
