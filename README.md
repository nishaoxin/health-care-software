# 居家康复助手

根据项目里的 v2.1 规范制作的 Windows 本地桌面首版。以肩外展、居家坐站的评估、训练提示和历史报告为核心，四个场景依次使用一路输入。

**在当前电脑上，双击 `启动康复助手.cmd` 即可打开软件。** 独立环境和官方 YOLO11n-pose 权重已准备；程序启动不会自动打开摄像头，也不会自动下载模型。

先选择“肩外展”，选择本机相机，预览并确认正面机位、测试侧和参与者，然后开始。停止后打开“历史报告”查看记录。只拍得到上半身时不要强行开展坐站或地面事件任务。

当前为可运行的工程首版。自动测试和模型接入已验证；真人动作准确度、摄像头现场表现、USB 拔插和长期运行仍需独立验收。

Git 已在本目录初始化，原始材料基线提交为 `3e55355`。本地数据、环境、权重和生成的测试文件不进入 Git；模型 hash 与完整依赖版本已记录。
