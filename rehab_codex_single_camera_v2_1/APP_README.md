# 居家康复助手使用说明

## 0.9.1 头颈侧位与肩内收

头颈前屈/后伸选择侧面机位，让所选侧的眼、耳、肩、髋入镜；不要求另一侧肩膀可见，也不需要露出皮肤。侧屈是另一项正面动作，需要双眼、双肩。无法测量时，画面下方和大字指导会指出缺失点；例如“左髋未看清”时应调整取景包含同侧髋，而不是转成正面。仍为实验性二维观察，不是颈椎关节活动度。

肩内收先向侧方抬臂到舒适位置，再点击“记录侧抬臂起点”并确认；不要求抬到水平。开始后在该起点保持约 1 秒，向身体缓慢收回，再抬回记录的起点计 1 次。不是从垂臂开始做外展，也不是横着抱胸。界面会显示起点角度及等待原因；舒适范围不足时不要勉强扩大幅度。更新后重新预览、记录起点，不沿用旧机位确认。

当前仍使用单路摄像头；双摄联合分析未实现。详细说明及验证边界见 `docs/NECK_SHOULDER_FIX_V0_9_1.md`。

## 0.9 默认镜像与大字指导

摄像头现在默认镜像，测试窗口和正式画面方向一致；只改变显示，本人左右侧不变。需要关闭时，在测试窗口取消“镜像预览”，或在“准备设置 → 更多设置”修改。本次启动内相机和回放分别记住显示选择，回放初始不镜像。

正式开始评估或训练后，默认自动进入全屏大字指导：当前动作文字为 36 像素，可调到 48 像素，旁边显示实时画面、次数和大图区域。“准备设置 → 更多设置 → 开始后自动放大”可关闭；也可点击“大字指导”重新打开。

按 Esc 或“返回普通界面”只退出大字显示，采集继续。需要停止时点击“停止采集”；要保存结果则点击“结束并保存”。训练暂停、组间休息和继续确认仍按原计划执行；看不清或断流时会显示大字暂停提示，不继续沿用旧动作图。

按本轮确认，暂不生成动作图片；大图区仍明确标注“示意图待补充”。以后补入核对过的对应侧别和阶段图片即可自动显示。详细边界见 `docs/DISTANCE_GUIDANCE_V0_9.md`。

## 0.8 人体导航与摄像头测试

打开软件后先进入身体评估。点击顶部“打开摄像头并测试”，即可独立检查画面；不必先选动作，不加载动作模型、不保存视频或评估记录。确认能看清自己后点击“关闭摄像头”，返回原页面。若连接失败，关闭后检查权限、设备占用与连接，再重试。

首页先显示人体图，不再堆放全部动作。点击关节图标或名称，右侧显示头颈、肩、肘、腕、手指、躯干、髋、膝、踝对应动作，再点击“选择动作”进入工作区。可搜索，也可主动点击“全部动作”。目前仍有 53 项任务，测量定义不变；人体图仅作菜单，不表示新增精细解剖测量能力。功能与边界见 `docs/BODY_NAVIGATION_V0_8.md`。

顶部摄像头选择全程序共用。启动优先恢复上次选择的设备和接口；没有保存偏好时，排除名称明确标为虚拟、红外、深度的设备后，只有一个有效候选就默认选中。存在多个候选、找不到上次设备或换接口时需手动选一次。切换模式不必再选相机，但仍须重新预览并确认机位，不自动采集。详细规则见 `docs/CLARITY_UI_V0_7.md`。

左侧主要入口为身体评估、训练中心、身体档案、历史记录。训练中心可以从评估记录选择动作，或继续当前准备中的训练安排；它不是自动处方或跨重启保存的计划库。日常活动及卧室/安全演示收在“其他工具”，仍须单独启动，未启动的场景没有监测。

工作区右侧分为“怎么做”和“准备设置”。前者有准备、动作、回位三步文字和左右侧图片位，可手动翻页。提示图片本轮不生成，缺图明确标记；补图方式见 `assets/exercise-guides/README.md`。打开预览时切到准备设置，正式开始后切回动作提示；只有有效观察才自动切换步骤，翻页不计次。底部随阶段依次显示打开预览、确认准备、开始和保存；停止采集在输入开启时保持可见。完整文字步骤位于“准备设置 → 更多设置”，测量说明单独展开，可选起点默认折叠，必需起点仍直接展示。相机接口和使用情境在“输入设置”中；实际来源/情境仍显示在画面下方。

身体档案默认只显示已有记录，区分可用评估和需补测；可展开未评估项目和完整明细。选中可用评估后点击“进入训练”，目标仍需单独确认。选中缺测记录时不能引用另一行的有效评估开始训练。

顶部“当前用户”现在选择本机档案；“新建用户”填写称呼后保存，“个人信息”可补充出生年份、关注侧别、康复原因、已知活动限制、生活目标、辅助器具和陪同情况。称呼以外均可留空，并记录本次填写者。旧用户编号与评估记录保持原样，可直接补充个人信息。

个人信息是手工记录，与摄像头结果分开展示，不代表专业审核，不自动改变目标或陪同要求。开始任务时将当时的档案版本保存到本地报告；修改档案不改写旧报告。切换用户清空本次目标、基线和训练引用，运行或报告待保存时不能切换/编辑。

训练按已确认计划执行组次、休息、暂停和结束反馈。评估清单支持选项、补测、跳过和重开继续。按 2026-09-09 最新要求，暂不继续扩展当前条件不足的精细关节/体表标志点，优先整理现有功能与前端，见 `docs/SPORT_UI_V0_6.md`。任务数不等同于全身全部关节已完成。

## 1. 软件的用途

单人、受控画面、主动开始使用。软件利用二维关键点观察一次居家康复任务，记录可见幅度、次数、时间和少量有依据的动作问题，保存到本机。

康复是核心。活动管理、卧室照护和安全报警是单独启用的配套场景。任何时刻只运行一路输入；其余场景未监测。软件不进行诊断、自动处方、跌倒概率预测或全屋监护。

## 2. 当前电脑启动

在上一层目录双击 `启动康复助手.cmd`。也可在本目录执行：

```powershell
.\.venv\Scripts\python.exe -m app.main
```

当前环境为 Windows x64 / Python 3.13.12 / PySide6 Widgets / CPU PyTorch。主依赖在项目 `.venv` 中；腕、踝、手指的可选组件独立放在 `.venv-landmarks`，不与主环境混装。系统 Python 和科研环境未修改。无需 CUDA、雷达或外接相机才能启动。

相同数据目录只允许一个应用实例。关闭窗口会先停止输入、保存任务，再退出。真实视频、骨架、参考截图默认不录制。

## 3. 第一次肩外展任务

1. 在顶部“当前用户”选择本人；第一次使用可点“新建用户”保存个人信息。在“身体评估”的动作库中选择“肩外展”。
2. 明确“实时摄像头”或“本地录像回放”，以及自主使用 / 受控演示 / 软件测试情境。
3. 核对顶部已选摄像头；首次有多个候选时按名称选一次。没有设备可选时点击刷新，或在“输入设置”中切换相机接口后重选。
4. 点击“打开预览”。预览显示画面和可用骨架，不累计正式业务。实际尺寸、接收速率与推理耗时显示在画面下方。
5. 确认正面机位与本人的解剖左 / 右侧。让测试侧髋、肩、肘进入画面。肘部纠错还需要腕点；躯干侧倾需要双肩和双髋。
6. 评估阶段按自己的舒适幅度活动，不设置统一幅度目标，不以常模判病。
7. 勾选“已确认单人、机位与舒适动作”，点击“确认准备”。计划需要陪同者时还须确认陪同者在场。
8. 点击“开始评估”，在舒适准备姿势保持约 1 秒，再做动作。回到准备姿势才记一次完整往返；记录足够连续有效画面才产生幅度汇总。
9. 点击“完成评估”。保存成功后进入“身体档案”；保存失败则留在待保存界面，重试成功后才能汇总。历史记录关闭软件后仍可重新查看。

如果模型或必要关键点不可用，软件会拒绝开始或暂停评价。腕点不可见时可以保留可靠的抬举角，肘部纠错显示无法评价；缺测不会转成 0° 或“动作差”。

### 身体信息与训练指导

汇总按当前用户、实时/回放来源和使用情境分开，展示 53 个任务的左右侧记录（共 106 项）：已评估、未评估或本次不可用。不要求完成全部项目。头颈/躯干侧屈的左右表示活动侧，前屈/后伸的左右表示拍摄测试侧；它们不是左右两个独立脊柱关节。每项取最新已结束评估；最新失败不会回退成旧成功。未测项目不填 0、不标正常。

需要一次评估多个项目时，点动作库或身体档案中的“本轮评估清单”，勾选动作与侧别并保存。选中一项进入评估，每项仍需单独预览、校准和确认；保存后重新打开清单继续。清单只关联从本轮入口开始的评估，历史成功和其他用户/来源的记录不会自动填入本轮。最新一次证据不足显示“需补测”；跳过需填写原因，可恢复为待测。“结束本轮”保留未完成状态和已有报告；之后可新建下一轮。关闭软件后本轮清单仍在，跳过不代表评估成功。

可以继续评估其他动作和侧别，也可选择已有评估点击“进入训练指导”。再点击“设置并确认训练计划”，由本人或专业人员确认次数、组数及可选角度目标。目标留空仍能观察动作并提供出程/回位文字提示，不判未达标。训练不会根据评估最大角度自动开目标或自动进阶。

重新预览并确认机位，点击“开始训练”。画面上方固定显示当前组、次数、阶段和操作按钮，随动作提供出程、回位提示；画面下方保留投影角和观察数据。提示音是可选的非语言声音。训练保存自身引用的评估快照；其他用户、动作或侧别的记录不能混用。原评估被删除或已更新时需要重新选择。

每组达到计划次数后进入休息，不再计动作；坐站仍在达到站位时计次，观察到回坐后进入休息，也可直接结束而保留已完成的起立。休息秒数可不填；填写后按该安排倒计时，但不会自动开始下一组。准备好后勾选“已确认本人、测试侧与机位未变”，再点“下一组”。识别不清或画面过期时不能继续。

“暂停训练”仅暂停计次，摄像头仍在预览；“停止采集”会真正释放摄像头并结束当前任务。恢复训练需重新确认并回到准备姿势，暂停前的半次动作不拼接成完整次数。休息与暂停不计入动作幅度和有效观察比例。计时跟随输入：实时相机使用单调时钟，录像使用媒体时间；没有新输入时倒计时不自行推进，也不补造有效观察。

最后一组完成后不再计次，点击“结束训练”保存。测量保存成功后，可填写疼痛、疲劳自评分及结束原因，也可跳过。未填与 0 分分开；这些是手工感受，不自动修改训练目标。历史报告可补填或修改感受，测量结果保持原样；填写保存失败保留表单。普通导出不含感受自由文本，本地报告仍可查看。

“身体档案”的“导出评估”可导出测量汇总 HTML/JSON。普通导出不包含个人档案中的姓名、出生年份和自由文本；这些内容只在本机个人信息与本地任务报告中展示。数据库升级至 v3，保留个人档案表并新增评估清单表；升级前在原库旁生成 `.before-v3-日期.bak`，旧会话内容不重写。备份失败会停止升级。不同模型、机位、规则、测量契约或记录条件不直接比较，不根据单个角度推断病情或恢复效果。

### 首批关节动作

可以按部位筛选肩、肘、髋、膝、腕、踝、手指、头颈和躯干。原关节用法见 [v0.3 关节说明](docs/JOINT_EXPANSION_V0_3.md)，新增方向与测量定义见 [v0.5 功能说明](docs/FUNCTIONAL_EXPANSION_V0_5.md)。新项目需在预览中记录舒适起点；标有“记录活动方向”的项目还需小幅试动作确认方向。原项目也可选录个人起点，不强迫进入统一伸直姿势。腕、踝、手指、头颈和躯干的新增观察均为实验性，尚无真人准确度验收。

| 动作 | 机位 | 必要关节点 / 说明 |
|---|---|---|
| 肩外展 | 正面 | 测试侧髋、肩、肘；向侧方抬臂并回位 |
| 肩前屈 | 侧面 | 测试侧髋、肩、肘；向前抬臂并回位 |
| 肘屈伸 | 侧面 | 测试侧肩、肘、腕；屈肘后伸肘回位 |
| 坐位膝屈伸 | 侧面 | 测试侧髋、膝、踝；坐稳后伸膝再回位，屈曲角随伸展减小 |
| 髋外展 | 正面 | 双髋与测试侧膝；以骨盆为参考，按已确认支撑安排侧移腿并回位 |
| 居家坐站 | 侧面 | 测试侧髋、膝、踝；需要下述坐位和站位基线 |

均为单摄像头二维投影，不是临床 ROM 测量。软件不能自动确认运动平面、是否始终坐稳/有扶物，也不能测肩内外旋、真实肌力或负重。准备姿势和动作分期参数是软件规则，不是医疗正常值；无法舒适完成时不要强行到位。

## 4. 居家坐站

选择“居家坐站”和指定近侧，使用侧面机位。画面应包含所选侧肩、髋、膝、踝以及完整任务区域。

在预览中，分别保持舒适坐位、舒适站位约 1 秒，使用“记录当前坐位”“记录当前站位”保存本次基线。基线稳定且可区分后再确认机位。

实时摄像头每次重新预览需要重新记录坐站基线。换设备、动作、侧别或机位会清除当前基线候选；历史数据仍保留，目标设置不会因此丢失。

录像回放可先定位到舒适坐位，点击“预览 1.2 秒片段”，再记录坐位；定位到稳定站位后重复此操作记录站位。最后重新定位至任务开始处、预览并确认。预览片段只做检查，不产生正式动作记录。

达到站位并稳定时记一次起立；观察到回坐后才允许下一次。最后一次已站起时停止仍保留该次，尚未观察到的下降时间为空。起立中途回坐记录部分尝试；缺测或换人不能补成完整起立。

这里是居家任务，不套用标准 5 次坐站临床常模，也不测真实负重、肌力或手部受力。双手 / 扶物使用由人设置或记录。

## 5. 日常活动管理

先在预览中选择“座椅”区域，用鼠标拖出矩形，再确认参与者和活动许可。只有此场景已开始时才累计可见时长。

默认可见坐位 2700 秒后提醒；可以勾选独立的演示阈值：坐位 15 秒提醒、站立任务 5 秒、步行任务 8 秒。演示阈值一直显示并写入报告，时钟不会被加速。

可选择站立 / 步行任务、延期、拒绝或停止。步行需要足够下肢、持续移动和腿部交替证据。只有上半身移动时不核销严格步行任务。“仅自报已完成”单独记录，不变成视觉核实。

缺测、出画、换人和长空档不补计；中断会重置连续久坐并中断活动任务。行为参数可以在运行前通过 `configs/scenes.yaml` 调整，重启后生效；每次会话保存自己的配置快照。

## 6. 卧室与安全演示

卧室需要床、床边、出口和地面关注区。没有真实床时保持“本次画面是真实床区”未勾选，结果会标记模拟区域演示。软件只记录可见床区、床边坐位 / 站位、已经观察到的出口过程。没看到人不等于已离床。

安全演示需要地面关注区；床、椅、沙发可作为排除区域。软件分别记录“观察到下降后的低位”和“持续低位，下降过程未观察”，只输出疑似事件和人工确认。

使用安全受控的低位动作或已获许可的回放，不进行真实跌倒或湿地试验。安全规则尚未完成实际家庭环境的误报 / 漏报评估。

事件处理顺序是“待查看 → 已查看 → 记录处理结果并关闭”。已查看不表示救援已到场。已有事件不会随切场景、断流、隐私暂停或报告删除自动消失。应用不发送远程通知。

## 7. 机位、回放与隐私

- 场景、输入、动作、侧别、机位、镜像或相关配置改变时结束旧任务。新输入重新预览和确认。
- ROI 保存为原始未镜像画面的归一化矩形。点击黑边不会创建区域。改变实际输入尺寸时结束当前任务，要求重新确认。
- 回放预览停在首个定位帧；开始后逐帧分析。调整起播时间或速度会结束原任务，创建新的预览。计时使用媒体时间，实际播放速率受 CPU 推理速度限制。
- 未提供可靠媒体时间的文件会停止分析；不使用推理耗时替代视频时间，也不自动猜恒定帧率。
- “停止采集”会释放设备并清空画面（原隐私暂停功能）。恢复通过“打开预览”手动进行，重新确认和开始，不续接旧半次动作。
- 若主动选择“同意保存本次逐帧骨架供调试”，本次报告可导出 `poses.jsonl`。未选择时不保存逐帧骨架。首版不提供原始视频 / 截图录制选项。
- 机位目前主要依赖人工确认；没有自动保证识别相机移动或精确视角。首版不提供旋转、裁剪和三维校准。

## 8. 保存、导出与故障处理

默认数据库：`data/home_rehab.sqlite3`，由一个写入线程拥有。数据目录已加入 Git 忽略规则。SQLite 没有默认加密，请使用本机合适的目录权限。

报告可导出 HTML、JSON、CSV、逐时指标与空的人工标注表。人工标签与预测字段分开。导出使用空的新目录，避免混入此前授权的骨架数据。导出失败不改变已经成功保存的主报告。

相同参与者、动作、侧别、设备引用、机位版本、来源 / 情境、目标 / 规则和模型条件下可比较记录；条件不同会拒绝直接比较。比较次数不会自动解释为康复改善。

部分 Windows 摄像头通过 DSHOW 首次启动需要数秒。预览会最多等待 15 秒取得第一帧；成功出画后，连续 3 秒没有新画面才判定输入离线。等待期间不要重复点击预览。

保存失败时停止采集并保留待保存快照。可“重试保存”，或将快照备份到其他可写目录；只有输入明确丢弃原因后才丢弃结果，并记录操作。旧采集未确认退出或未保存结果未处理时，不打开新输入。

正常退出会保存本次任务。异常退出后的 `RUNNING` 记录会标记中断，不补造结束时间和未保存动作。首版没有逐帧数据库检查点；操作系统崩溃前尚未提交的内存指标可能丢失。
