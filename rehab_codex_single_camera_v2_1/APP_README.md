# 居家康复助手使用说明

## 1. 软件的用途

单人、受控画面、主动开始使用。软件利用二维关键点观察一次居家康复任务，记录可见幅度、次数、时间和少量有依据的动作问题，保存到本机。

康复是核心。活动管理、卧室照护和安全报警是单独启用的配套场景。任何时刻只运行一路输入；其余场景未监测。软件不进行诊断、自动处方、跌倒概率预测或全屋监护。

## 2. 当前电脑启动

在上一层目录双击 `启动康复助手.cmd`。也可在本目录执行：

```powershell
.\.venv\Scripts\python.exe -m app.main
```

当前环境为 Windows x64 / Python 3.13.11 / PySide6 Widgets / CPU PyTorch。所有依赖在项目 `.venv` 中，系统 Python 和科研环境未安装或修改新依赖。无需 CUDA、雷达或外接相机才能启动。

相同数据目录只允许一个应用实例。关闭窗口会先停止输入、保存任务，再退出。真实视频、骨架、参考截图默认不录制。

## 3. 第一次肩外展任务

1. 选择“康复评估与训练”，动作为“肩外展”。评估模式记录表现；训练模式允许已设置的动作反馈。
2. 明确“实时摄像头”或“本地录像回放”，以及自主使用 / 受控演示 / 软件测试情境。
3. 点击“刷新设备”，按名称人工选择设备。当前 DSHOW 枚举发现 `HD Webcam`；这只是枚举结果，不等于完成相机画面或动作验证。没有设备可选时可明确切换 MSMF 后端重新枚举。
4. 点击“预览输入”。预览显示画面和可用骨架，不累计正式业务。摄像头的实际尺寸、接收速率与推理耗时显示在画面上方。
5. 确认正面机位与本人的解剖左 / 右侧。让测试侧髋、肩、肘进入画面。肘部纠错还需要腕点；躯干侧倾需要双肩和双髋。
6. 如需个人目标，点击“设置个人目标与计划”。目标默认未设置，只测量，不判未达标。不同参与者请使用不同匿名编号。
7. 人工勾选“已确认单人、机位与舒适动作”，点击“确认机位”。计划需要陪同者时还须确认陪同者在场。
8. 点击“开始任务”，在舒适准备姿势保持约 1 秒，再按已经确认的计划做动作。回到准备姿势才记一次完整往返；完整往返与达到目标分别记录。
9. 点击“停止并保存”。在“历史报告”中打开记录，关闭软件后仍可重新查看。

如果模型或必要关键点不可用，软件会拒绝开始或暂停评价。腕点不可见时可以保留可靠的抬举角，肘部纠错显示无法评价；缺测不会转成 0° 或“动作差”。

## 4. 居家坐站

选择“居家坐站”和指定近侧，使用侧面机位。画面应包含所选侧肩、髋、膝、踝以及完整任务区域。

在预览中，分别保持舒适坐位、舒适站位约 1 秒，使用“记录当前坐位”“记录当前站位”保存本次基线。基线稳定且可区分后再确认机位。

实时摄像头每次重新预览需要重新记录坐站基线。换设备、动作、侧别或机位会清除当前基线候选；历史数据仍保留，目标设置不会因此丢失。

录像回放可先定位到舒适坐位，点击“预览 1.2 秒片段”，再记录坐位；定位到稳定站位后重复此操作记录站位。最后重新定位至任务开始处、预览并确认。预览片段只做检查，不产生正式动作记录。

达到站位并稳定时记一次起立；观察到回坐后才允许下一次。最后一次已站起时停止仍保留该次，尚未观察到的下降时间为空。起立中途回坐记录部分尝试；缺测或换人不能补成完整起立。

这里是居家任务，不套用标准 5 次坐站临床常模，也不测真实负重、肌力或手部受力。双手 / 扶物使用由人设置或记录。

## 5. 日常活动管理

先在预览中选择“座椅”区域，用鼠标拖出矩形，再确认参与者和活动许可。只有此场景已开始时才累计可见时长。

默认可见坐位 2700 秒后提醒；可以勾选独立的演示阈值：坐位 15 秒提醒、站立任务 5 秒、步行任务 8 秒。演示阈值一直显示并写入报告，时钟不会被加速。

可选择站立 / 步行任务、延期、拒绝或停止。步行需要足够下肢、持续移动和腿部交替证据。只有上半身移动时不核销严格步行任务。“仅自报已完成”单独记录，不变成视觉核实。

缺测、出画、换人和长空档不补计；中断会重置连续久坐并中断活动任务。行为参数可以在运行前通过 `configs/scenes.yaml` 调整，重启后生效；每次会话保存自己的配置快照。

## 6. 卧室与安全演示

卧室需要床、床边、出口和地面关注区。没有真实床时保持“本次画面是真实床区”未勾选，结果会标记模拟区域演示。软件只记录可见床区、床边坐位 / 站位、已经观察到的出口过程。没看到人不等于已离床。

安全演示需要地面关注区；床、椅、沙发可作为排除区域。软件分别记录“观察到下降后的低位”和“持续低位，下降过程未观察”，只输出疑似事件和人工确认。

使用安全受控的低位动作或已获许可的回放，不进行真实跌倒或湿地试验。安全规则尚未完成实际家庭环境的误报 / 漏报评估。

事件处理顺序是“待查看 → 已查看 → 记录处理结果并关闭”。已查看不表示救援已到场。已有事件不会随切场景、断流、隐私暂停或报告删除自动消失。应用不发送远程通知。

## 7. 机位、回放与隐私

- 场景、输入、动作、侧别、机位、镜像或相关配置改变时结束旧任务。新输入重新预览和确认。
- ROI 保存为原始未镜像画面的归一化矩形。点击黑边不会创建区域。改变实际输入尺寸时结束当前任务，要求重新确认。
- 回放预览停在首个定位帧；开始后逐帧分析。调整起播时间或速度会结束原任务，创建新的预览。计时使用媒体时间，实际播放速率受 CPU 推理速度限制。
- 未提供可靠媒体时间的文件会停止分析；不使用推理耗时替代视频时间，也不自动猜恒定帧率。
- 隐私暂停会释放采集设备和清空画面。恢复通过“预览输入”手动进行，重新确认和开始，不续接旧半次动作。
- 若主动选择“同意保存本次逐帧骨架供调试”，本次报告可导出 `poses.jsonl`。未选择时不保存逐帧骨架。首版不提供原始视频 / 截图录制选项。
- 机位目前主要依赖人工确认；没有自动保证识别相机移动或精确视角。首版不提供旋转、裁剪和三维校准。

## 8. 保存、导出与故障处理

默认数据库：`data/home_rehab.sqlite3`，由一个写入线程拥有。数据目录已加入 Git 忽略规则。SQLite 没有默认加密，请使用本机合适的目录权限。

报告可导出 HTML、JSON、CSV、逐时指标与空的人工标注表。人工标签与预测字段分开。导出使用空的新目录，避免混入此前授权的骨架数据。导出失败不改变已经成功保存的主报告。

相同参与者、动作、侧别、设备引用、机位版本、来源 / 情境、目标 / 规则和模型条件下可比较记录；条件不同会拒绝直接比较。比较次数不会自动解释为康复改善。

保存失败时停止采集并保留待保存快照。可“重试保存”，或将快照备份到其他可写目录；只有输入明确丢弃原因后才丢弃结果，并记录操作。旧采集未确认退出或未保存结果未处理时，不打开新输入。

正常退出会保存本次任务。异常退出后的 `RUNNING` 记录会标记中断，不补造结束时间和未保存动作。首版没有逐帧数据库检查点；操作系统崩溃前尚未提交的内存指标可能丢失。

## 9. 换电脑与开发

安装 Python 3.13 后，在本目录运行独立环境安装脚本；普通启动不会执行这些联网准备步骤：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1 -PrepareModel
# 当前网络较慢时，可以显式选择清华 PyPI 镜像：
powershell -ExecutionPolicy Bypass -File scripts/setup.ps1 -IndexUrl https://pypi.tuna.tsinghua.edu.cn/simple -PrepareModel
```

官方权重下载地址和固定 SHA256 在 `assets/models/manifest.json`。不存在可信清单或 hash 不符时不加载模型。44 个本次安装 wheel 已逐一与官方 PyPI SHA256 核对，见 `docs/DEPENDENCY_MANIFEST.json`。

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts/qa_desktop.py
.\.venv\Scripts\python.exe scripts/list_cameras.py --backend dshow
```

`app/` 是新增应用；原 `camera_reference.py`、`geometry_reference.py` 和参考测试继续保留。`MANIFEST.sha256.json` 仍表示原实施包，不是本次应用所有文件的发布清单。

当前交付源码、已准备环境、双击启动入口；未产出免 Python 安装包。模型、数据和第三方许可见 `docs/THIRD_PARTY_NOTICES.md`；验收状态见 `docs/VALIDATION_WINDOWS.md`。
