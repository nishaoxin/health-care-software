# v2.0 → v2.1 变更说明

## 简洁界面与共享摄像头 · 2026-09-09

- 删除宣传横幅、重复标题和动作卡片上的重复说明/空图片位。具体动作文字和图片位保留在“怎么做”，详细说明折叠；53 项任务不删减。
- 底部按阶段只突出当前主要操作，实时指导固定可见；保留停止采集、人工确认、保存失败重试/备份/丢弃。
- 全局输入栏启动即显示设备。恢复上次 path/backend，首次可选唯一非明确虚拟/红外/深度候选；不按索引 0 猜设备，不自动打开或开始任务。
- 手动设备选择及成功机位确认后记住设备；切场景、子模式、动作和回放往返沿用选择但不沿用基线/机位确认。偏好保存失败不干扰报告保存。
- 更换接口清除旧设备候选，忽略迟到的旧接口枚举；全局来源变化清空不匹配身体档案显示。说明见 `docs/CLARITY_UI_V0_7.md`。

## 运动 App 风格前端与动作图解 · 2026-09-09

- 按用户最新要求恢复前端改进，暂停精细关节/标志点扩展。保留 53 项现有任务、原模型和测量规则。
- 新增评估流程区、运动式动作卡片、训练中心，以及准备/动作/回位文字和左右侧图片位。不生成或下载提示图。
- 图解按有效观察跟随阶段，缺测、断流、暂停时停止相应自动提示；翻页不驱动计数。拍摄准备与图解分开显示。
- 新入口保留训练引用、计划确认和未保存门禁；旧评估时间为空不再导致进入训练界面异常。
- 素材约定、范围和验证方法见 `docs/SPORT_UI_V0_6.md`。

## 功能优先：扩展动作与本轮评估 · 2026-09-08

- 按最新要求暂停视觉打磨，仅增加功能所需入口。
- 新增 14 项手指伸展起点任务：从舒适屈曲起点伸展、回屈后计次，目标判断采用屈曲角减小方向；不是新增 14 个解剖关节。
- 新增头颈和躯干各 3 项整体投影观察，均需舒适起点和方向校准；明确不输出颈椎/胸腰椎各节段活动度。原模型和单路输入保持不变。
- 新增本轮评估清单：明确选择项目与左右侧、逐项评估/补测、带原因跳过、恢复待测、结束本轮与重开继续。仅关联本轮记录，不借用旧成功或其他人的结果。
- SQLite v3 迁移前备份，保留旧会话与个人档案。运行或待保存时不修改清单；开始前重新校验清单、身份、来源与侧别。
- 当前为 53 项任务、106 个侧别记录入口，不声称全部关节方向或真人精度已完成。定义、限制和剩余范围见 `docs/FUNCTIONAL_EXPANSION_V0_5.md`。

## 训练执行与结束反馈 · 2026-09-08

- 已确认计划实际驱动每组次数、组间休息和最后一组结束；组间手动继续，不自动加量。可空休息时间保留为未指定。
- 暂停/休息不计动作或质量证据，恢复和下一组需确认本人、侧别、机位并取得有效新画面；迟到帧不接入恢复后的计数。坐站仍在站位计次，未观察的下降时间保持空值。
- 组次、暂停与继续节点及时保存；保存失败释放采集并保留待保存结果。结束后可填写手工感受，支持失败重试、版本冲突和报告重开，不修改测量结果。
- 训练按钮固定在画面上方，小窗口滚动时仍能操作；计划对话框支持滚动，退出采集与暂停训练明确区分。
- 修复识别错误后残留旧观察，以及被拒绝的训练操作导致后续提示音失效。分批验证见 `docs/VALIDATION_WINDOWS.md`，不把未跑完整回归或合成流程当作实机验收。

## 本地个人档案 · 产品完善第二阶段（部分） · 2026-09-08

- 手工个人信息独立保存，支持可空出生年份、侧别、康复原因、限制、目标、器具、陪同情况与填写者；不推断疾病或修改训练处方。

- 身体档案分开展示手工信息与视觉记录；准备区提示已填活动限制和陪同需求。本地任务保存开始时的个人档案快照，普通导出排除这些个人信息。
- 已验证真实运行层/数据库的新建、保存、切换、重开，以及迁移备份、只读、冲突、错误状态；训练组次与休息执行及全关节扩展仍待完成。
