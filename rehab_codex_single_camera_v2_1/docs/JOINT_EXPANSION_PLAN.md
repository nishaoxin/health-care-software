# 关节评估完善：执行与验收记录

用户目标：进一步完善，争取把能做到的关节评估都做到。
2026-09-08 已明确同意将腕、踝、手指一并纳入，并允许增加必要的本地依赖与官方模型。当前软件实现与边界见 `JOINT_EXPANSION_V0_3.md`，不能把工程实现说成全部关节均可临床评估。

## 固定边界

仍为用户主动开始、单路 RGB 摄像头或明确标签的回放；不进行医学诊断、自动处方或精确三维/肌力/负重测量。新组件不打开第二个摄像头。缺点、遮挡、运动平面不符或多人/多手归属不明时拒测，不补点、不填零。原数据、模型和可运行环境保留。

## 要交付的完整范围

1. 肩/肘/髋/膝：审计屈、伸、外展/内收等在指定相机平面可观察的方向，补充目前未提供的动作与反向起始方式，不能只改名字或重复计同一动作充数。
2. 舒适起始姿势：允许活动受限的人记录本人起始角，不强迫达到统一健康人阈值；保存来源/人物/侧别/动作/机位/时间等校准证据，变更后失效。
3. 腕：补手部参考关键点，在明确屈伸/桡尺偏拍摄平面下测量可见投影；不能将手臂移动当腕关节活动。
4. 踝：补足跟/足尖，在指定侧面测背屈/跖屈投影；不将膝角、踝位置或抬腿等同踝关节角。缺乏足部解剖轴的内外翻明确边界。
5. 手指：手部近景，支持拇指及其余四指可见关节的屈伸投影，区分 MCP/PIP/DIP 或拇指 MCP/IP，记录缺测；不以掌指或整指总值冒充所有关节已测。
6. 覆盖清单：逐项标记支持条件、所需组件、仍不能可靠测的方向及原因。颈/躯干只能有条件报告可见姿态代理量时，须与真正关节评估分开；不把“有按钮”算实现。
7. 汇总与训练：不再固定十二项；新动作进入身体信息、原始评估报告、导出和训练引用校验。保留左右/用户/来源隔离、缺失状态、模型/测量定义版本，旧记录不能被静默换定义。
8. 验收：各指标已知几何、遮挡与退化几何、镜像与比例、方向/校准、时间连续性、计数边界、数据回写/重开、界面完整路径；官方模型真实加载与推理和原有回归。真人准确度需独立对照，不能用合成测试冒充。
9. 更新后本地提交并尝试推送指定 GitHub main，核对远端。当前已知上传缺少可用账号授权，不能称已上传。

## 已核对依据

- [Ultralytics Pose 输出](https://docs.ultralytics.com/tasks/pose/) 与本地骨架定义：当前 COCO17 没有足跟/足尖或手指关节。
- [MediaPipe Pose](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker)：33 点包含足跟、足部前端和手部参考点；它们是模型估计，不是临床精度保证。
- [MediaPipe Hand](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/python)：21 手部点；左右手分类分数不能当作每个关节点的定位置信度。
- [Kinovea 二维标定说明](https://www.kinovea.org/help/en/measurement/calibration.html)：平面/拍摄条件限制必须明确。
