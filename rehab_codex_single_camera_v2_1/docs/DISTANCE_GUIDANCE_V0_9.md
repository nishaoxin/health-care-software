# 默认镜像与远距离大字指导 · 0.9

2026-09-09 用户要求：摄像头默认镜像；人距离电脑较远时，边做动作边看大字和图片提示。用户再次明确本轮不生成动作图片。

## 使用方式

- 摄像头测试、普通工作区和大字指导默认镜像。可在测试窗口或“准备设置 → 更多设置 → 镜像预览”关闭；本次启动内跨动作、场景沿用选择。实时相机和本地回放分别保留显示选择，回放初始为原向；重启后相机恢复默认镜像。
- 正式开始评估或训练后自动进入全屏大字指导。主动作文字默认 36 像素，右上角可选 32 / 36 / 40 / 48；次数和重要状态单独放大，保留实时摄像头画面和大图区。
- 普通工作区的“大字指导”可重新打开；“准备设置 → 更多设置 → 开始后自动放大”可以关闭自动进入。放大界面不自动打开摄像头、确认机位或开始任务。
- 点击“返回普通界面”或按 Esc 只退出大字显示，相机/任务继续；页面明确标注这一点。需关闭相机请点“停止采集”；“结束并保存”走原有保存流程。
- 训练暂停、继续和下一组复用既有控制门禁；继续/下一组前仍须确认本人、侧别与机位，休息未结束不启用下一组。休息剩余时间取自训练引擎，不另造计时器。

## 显示与安全边界

- 不更换模型、不重算角度、不调用第二次识别，不修改计数规则、个人目标或正式用户数据库。大字窗口消费同一运行视图；可显示同一帧，但不创建采集句柄。
- 镜像通过绘制变换完成；原始 BGR 帧、关键点坐标、左右侧标签和 ROI 存储不翻转。画面上的骨架/ROI 与镜像一致，点击继续逆映射回原图。动作示意图不随相机镜像翻转，也不借用相反侧图片。
- 图解仍按当前动作、本人侧别、准备/动作/回位三阶段选择。大字提示使用原有逐阶段文字；完整摆位与拍摄说明保留在准备设置中。
- 只有主指标有效且 observation_status=VALID 才显示实时动作提示。缺人、多人、关键点不足、未知阶段、暂停、休息、完成、错误和离线时不保留上一张动作图，而是显示大字状态。
- 当前训练质量提醒优先于动作示范；训练引擎明确提示目标范围后回位、到达站位、幅度观察和坐站组次完成时，回位图文不能与旧出程图相冲突。仅依现有阶段和引擎反馈切换展示，不另设目标判定。
- 实时画面超过 3 秒没有新鲜帧时，显示层清空旧画面并提示暂停动作；不继续显示过期纠错。这个界面保护不补造临床暂停事件或计数；底层原有断流/保存协议不变。
- 用户主动结束且保存成功后关闭大字界面，回到原有结果流程；意外断流即使已保存中断报告，仍保留远距离可见的大字警告。SAVE_FAILED 返回普通界面处理重试/备份/明确丢弃，不提供绕过保存的入口。
- 长错误/反馈保留在普通界面和工具提示内，大字区只显示可读摘要，避免挤掉停止按钮。无截图/录像授权时不会把大字窗口中的画面保存到用户目录。

## 图片状态

本轮不生成、不下载任何动作示范图。大图区明确显示“示意图待补充”；图片路径、侧别、阶段、尺寸/文件大小检查仍遵循 `assets/exercise-guides/README.md`。放入经授权和核对的 PNG 后按需加载、等比例缩放，不裁切身体或拉伸。测试中的纯色图片仅为临时工程夹具，不是患者示范素材。

工程与本机启动验证见 `VALIDATION_WINDOWS.md`；没有真人远距离可读性、视力适配、高 DPI 或临床使用验收，不能承诺固定几米距离下人人可读。
